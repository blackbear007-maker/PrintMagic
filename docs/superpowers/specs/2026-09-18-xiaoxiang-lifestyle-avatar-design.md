# 印象魔法・小象生活系頭像設計

## 背景

印象魔法目前使用的 `public/xiaoxiang.jpg` 是藍紫色象頭插畫，穿深色有領上衣與紫色滾邊，視覺上偏吉祥物／制服。這次改版要參考母專案《就快到了》與《單單環島》的角色素材系統，改成小象的年輕成年擬人形象，並以 Google Cloud Vertex AI 額度生成一組可供介面切換的生活系頭像。

本規格只處理小象頭像與印前助手介面接入，不改變印前處理管線、對話文案或其他角色資產。

## 已確認的視覺方向

- 採用《就快到了》的高完成度角色插畫風格：乾淨線稿、細緻賽璐璐光影、年輕成年比例、自然的半身構圖。
- 採用《單單環島》的系列頭像邏輯：同一張臉、髮型、身形與服裝，只變化表情、視線、手勢與小幅姿態。
- 小象維持母專案的角色識別：約 28–32 歲、乾淨年輕臉、金髮武士頭、可靠而略慵懶。
- 印象魔法版不使用墨鏡、車衣、車褲、單車、健身房制服或健身器材。
- 固定服裝：霧藍色針織上衣＋卡其色休閒褲。
- 不加固定配件：不戴眼鏡、不戴帽子、不背包、不掛識別牌、不放品牌 Logo。
- 整體要像日常生活中的小象，而非印刷業吉祥物或運動教練宣傳照。

## 頭像系列

第一版生成五種核心狀態，各自再生成一張自然眨眼版本，共十張：

| 狀態 | 畫面語意 | 手勢／表情限制 |
|---|---|---|
| `idle` | 平靜待機，略帶「喔」的慵懶表情 | 不誇張微笑，不露齒大笑 |
| `hello` | 看向使用者，輕鬆打招呼 | 一手小幅抬起即可，不做熱血揮手 |
| `think` | 正在檢查影像品質或思考 | 眼神略移、眉眼收斂，手指可輕觸下巴，不拿道具 |
| `thumbs` | 對印刷結果表示「可以」 | 小幅比讚，表情克制，不做勝利姿勢 |
| `cheer` | 完成處理或輸出成功 | 小幅握拳或抬手，保留小象的低能量幽默感 |

所有狀態使用相同的 1:1 畫布與近似裁切位置，讓介面切換時頭部不跳動。角色占畫布高度約 78–86%，臉部與上半身保留足夠清晰度，縮小至 32–96px 時仍能讀到眼神與嘴角。

## 背景與輸出

- 使用低對比、柔和的藍灰／暖灰生活背景，避免抽象魔法光效、印刷機、健身房與單車場景。
- 背景可以有輕微室內或街角生活感，但不得出現可讀文字、品牌、招牌、Logo、額外人物或道具。
- 既有 `public/xiaoxiang.jpg` 路徑保留，作為 `idle`／網站 icon 的主圖；新增狀態檔案放在 `public/xiaoxiang/`。
- 預定檔案：`idle.webp`、`idle-blink.webp`、`hello.webp`、`hello-blink.webp`、`think.webp`、`think-blink.webp`、`thumbs.webp`、`thumbs-blink.webp`、`cheer.webp`、`cheer-blink.webp`。
- 生成原檔先保留於受版本控制的資產目錄；只有通過完整性與視覺檢查後才覆蓋／新增正式路徑。

## Google Cloud 生成策略

1. 優先使用 Google Cloud Vertex AI `gemini-3.1-flash-lite-image`。
2. 若同一專案短時段配額回傳 429，才改用同一專案的 `gemini-2.5-flash-image`，不可改用未授權的第三方生成服務。
3. 先生成一張角色母版，再把母版作為參考圖生成其餘狀態，避免臉型、髮型與服裝漂移。
4. 憑證只讀本機 gcloud ADC 或既有 Google Cloud 環境變數，不寫入原始碼、manifest、前端 bundle 或 Git。
5. 生成記錄需包含模型、Google Cloud project、時間、狀態、檔案尺寸與 SHA-256；不記錄 access token。
6. 雲端憑證或權限不可用時，不建立假圖、不破壞既有 `xiaoxiang.jpg`，介面繼續使用目前素材。

## AI2PNG 介面接入

- 保留現有 `XiaoxiangAssistant` 的對話卡與點擊互動。
- 將頭像切換抽成有限狀態映射：待機使用 `idle`，收到圖片／處理中使用 `think`，處理完成使用 `thumbs` 或 `cheer`，招呼使用 `hello`。
- 眨眼只在目前狀態的 `*-blink` 資產存在且使用者未開啟減少動態偏好時觸發；狀態切換期間不得把新狀態覆蓋回舊狀態。
- 若某一張狀態素材載入失敗，退回 `idle`，再退回既有 `xiaoxiang.jpg`；不可讓助手區塊破圖或阻塞主要印前流程。
- PWA precache 清單同步加入正式狀態資產，讓離線模式仍可使用頭像系列。

## 驗收

- 五種核心狀態與五種眨眼版本均存在，圖片格式與尺寸正確。
- 十張圖的人臉、髮型、年齡感、霧藍上衣與卡其褲一致。
- 無車衣、健身制服、墨鏡、帽子、背包、Logo、可讀文字、浮水印、額外人物或多餘肢體。
- 頭像在 32px、64px、96px 顯示時仍能辨認表情，頭部位置不因狀態切換而明顯跳動。
- AI2PNG `typecheck`、`build` 與既有測試通過；離線載入時所有正式頭像請求都能從 precache 命中。
- Google Cloud 生成失敗時既有介面仍可啟動，且原本的 `xiaoxiang.jpg` 不被刪除或寫壞。

## 非本次範圍

- 不重新設計印象魔法的整體 UI 視覺。
- 不改寫小象對話文案或角色 system prompt。
- 不把《就快到了》的車衣、墨鏡或單車素材搬進印象魔法。
- 不生成完整場景插畫、宣傳海報或其他角色頭像。
